# Exchanges

## What can be exchanged

You can exchange an item for the same item in a different size or color within the return window.

## Price differences

If the new size or color costs more, we charge the difference. If it costs less, we refund the difference to your original payment method.

## How to request one

Start a return from your order page and choose "Exchange" as the reason. We send the replacement once we receive the original item.

## Items that cannot be exchanged

Final Sale items cannot be exchanged. Gift cards cannot be exchanged or returned.
