# Warranty vs Returns

## Returns

A return is for a change of mind. It has a time limit from delivery and requires the item to be unused.

## Warranty

The warranty covers manufacturing defects. It is not limited by the 30-day return window, and it applies even to Final Sale items.

## Which should I use?

If the item is defective, use the warranty. If you simply changed your mind, use a return. In both cases, start from your order page or open a support ticket.
