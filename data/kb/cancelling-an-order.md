# Cancelling an Order

## Before it ships

You can cancel an order at no cost before it ships. Open the order and choose "Cancel", or open a support ticket with your order number.

## After it ships

Once an order has shipped, it cannot be cancelled. You can return it under the Returns Policy when it arrives.

## Final Sale items

You can cancel an order containing Final Sale items before it ships.
