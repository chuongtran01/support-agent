# Holiday Returns

Shopping for someone else? We make returns easy so gifts can be swapped without stress.

## Extended returns

Returns are accepted within 45 days of delivery. Items must be unused and in original packaging with proof of purchase.

## Gift returns

If you received a gift, ask the buyer for the order number. We can issue store credit to the recipient without a receipt.

## Refunds

Refunds go to the original payment method within 5 to 7 business days of receiving the return.
